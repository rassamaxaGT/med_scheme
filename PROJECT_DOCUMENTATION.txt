ДОКУМЕНТАЦИЯ ПРОЕКТА: МЕДРИСУНОК - УЗИ РЕДАКТОР (MEDRISUNOK)

Данный документ содержит Техническое задание (ТЗ) и подробное описание Архитектуры проекта для передачи заказчику.

========================================================================
ЧАСТЬ 1: ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ)
========================================================================

1. ОПИСАНИЕ ПРОЕКТА
«МедРисунок - УЗИ Редактор» — это специализированное кроссплатформенное графическое приложение, разработанное для врачей УЗИ-диагностики, гинекологов и хирургов. 
Приложение работает как «медицинская раскраска», позволяя врачу быстро наносить специфические патологии и маркеры на стандартизированные анатомические схемы или загруженные снимки УЗИ. Приложение работает полностью локально, не собирает и не хранит персональные данные пациентов (ПДн), что исключает любые риски утечки конфиденциальной информации.

2. ПОДДЕРЖИВАЕМЫЕ ПЛАТФОРМЫ
- Планшеты и смартфоны на базе Android / iOS / HarmonyOS (особый упор сделан на поддержку стилусов).
- Персональные компьютеры, ноутбуки и рабочие станции (запуск в любом современном веб-браузере без установки программ).

3. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

3.1. Работа с холстом и фоновыми изображениями
- Импорт фоновой схемы: Возможность загрузить изображение УЗИ-снимка или базовой анатомической схемы из галереи устройства (на мобильных) или выбрать файл с диска (на ПК и в Web-версии).
- Удаление фона: Возможность мгновенно очистить фоновое изображение для рисования на чистом белом листе.

3.2. Специализированный медицинский инструментарий (Маркеры патологий)
- Кисть «Колючая проволока»: Для разметки областей эндометриоидного инфильтрата.
- Кисть «Паутина»: Для указания спаечного процесса брюшной полости.
- Шоколадный овал: Залитая полупрозрачная область коричневого цвета для разметки эндометриомы.
- Розовый овал: Полупрозрачная область бледно-розового цвета для обозначения миомы матки.
- Штамп «ВМС» (Спираль): Нанесение знака внутриматочной спирали.
- Штамп «Очаг» (Пятно): Разметка эндометриоидных очагов.
- Стрелки с текстом: Инструмент указания направления с открывающимся диалоговым окном для ввода аннотации (текст автоматически прикрепляется к основанию стрелки).
- Обычная кисть и Ластик: Для произвольного рисования линий и удаления ошибочно нанесенных штрихов.

3.3. Управление жестами, масштабированием и поддержка стилусов
- Инструмент «Перемещение»: Возможность выделить любой нарисованный ранее объект (линию, овал, стрелку), переместить его по холсту или изменить его размеры с помощью интерактивной рамки.
- Масштабирование и панорамирование (Zoom & Pan): Перемещение всего холста по экрану и его приближение/удаление двумя пальцами (жест pinch-to-zoom) для детальной прорисовки.
- Интеллектуальная работа со стилусом:
  * Игнорирование ладони (Palm Rejection): Случайные касания холста рукой во время рисования стилусом игнорируются.
  * Давление пера: Толщина линии динамически меняется в зависимости от силы давления пера стилуса на экран.

3.4. Сохранение, загрузка проектов и экспорт результатов
- Сохранение директории:
  * На Android: Выбор папки через стандартный механизм Storage Access Framework (SAF) с сохранением постоянных прав (persistable permission), чтобы приложение не запрашивало доступ повторно.
  * На iOS: Автоматическое сохранение в защищенную папку «Документы» приложения, доступную для копирования в стандартном приложении «Файлы».
  * На Web (в браузере): Автоматическое скачивание и загрузка файлов через стандартные папки браузера.
- Проприетарный формат проекта «.meddraw»: Файлы сохраняются в виде ZIP-архива, содержащего фоновый снимок (background.png) и текстовый файл (project.json) с векторными координатами всех нанесенных патологий. Такой проект можно открыть на любом другом устройстве для продолжения редактирования.
- Плоский экспорт: Сохранение объединенного изображения (снимка вместе со всеми нарисованными отметками) в формате PNG в галерею устройства или в папку загрузок.


========================================================================
ЧАСТЬ 2: АРХИТЕКТУРА ПРОЕКТА
========================================================================

Архитектура проекта построена в соответствии с принципами Clean Architecture (Чистой архитектуры) с разделением кода по функциональным фичам (Feature-First подход), что обеспечивает независимость логики от платформы запуска и системных компонентов.

1. АРХИТЕКТУРНЫЕ СЛОИ (КОМПОНЕНТЫ)
- Domain (Домен): Слой чистой бизнес-логики. Содержит модели разметки (DrawAction), сущность проекта (ProjectData) и описание абстрактного интерфейса репозитория (ProjectRepository). Слой не зависит от внешних библиотек и фреймворков.
- Data (Данные): Слой работы с внешними источниками информации. Отвечает за сериализацию моделей рисования в JSON и сохранение данных в файлы.
- Presentation (Представление): Слой интерфейса. Содержит блоки управления состоянием на базе flutter_bloc (DrawBloc и ProjectBloc), интерактивный виджет холста (CanvasWidget) и перетаскиваемый тулбар (FloatingToolbox).

2. КРОССПЛАТФОРМЕННОСТЬ И УСЛОВНЫЙ ИМПОРТ (CONDITIONAL IMPORTS)
Для запуска одного и того же кода на мобильных устройствах (требующих работы с файловой системой) и в браузерах (где файловая система ограничена) применена технология условной компиляции Dart:
- Репозиторий проектов (ProjectRepository):
  Регистрируется через провайдер. На мобильных платформах Flutter компилирует класс, работающий с диском, а на Web — класс, выполняющий все манипуляции с ZIP-архивом напрямую в оперативной памяти с выдачей готового файла через триггер скачивания в браузере.
- Загрузчик изображений (image_loader):
  Абстрагирует холст от платформенной логики. На мобильных устройствах читает байты снимка по прямому файловому пути. На Web загружает выбранный файл в Blob URL в памяти браузера, позволяя рендерить его без обращения к диску.
- Браузерный хелпер (web_helper):
  Вызывает JS-интероп для работы с браузерным API загрузок. На мобильных устройствах замещается пустыми заглушками во время компиляции, предотвращая сбои.

3. ОПТИМИЗИРОВАННЫЙ РЕНДЕРИНГ
Отрисовка разметки производится в классе CanvasPainter:
- Отрисовка выполняется на холсте Canvas Flutter.
- Специальные кисти («колючки» инфильтрата и «паутина» спаек) генерируются динамически по математическим алгоритмам с использованием PathMetrics, что гарантирует плавную отрисовку без задержек.
- Текст стрелок аннотаций позиционируется в экранных координатах поверх масштабируемого холста, благодаря чему текст и наконечники стрелок остаются четкими, не искажаются и не размываются при сильном масштабировании (зуме) снимка.
