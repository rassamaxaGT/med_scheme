# Руководство по сборке и установке «МедРисунок» (MedRisunok)

В данном руководстве описан процесс автоматической сборки дистрибутивов и их установки на конечные устройства врачей: **Android (планшеты и смартфоны)**, **Windows (ПК и ноутбуки)** и **iOS (iPad и iPhone)**.

---

## Часть 1. Сборка установщиков

Все дистрибутивы автоматически помещаются в каталог `dist/` в корне проекта:
```
dist/
├── android/
│   ├── MedRisunok_v1.0.30_universal.apk   # Универсальный APK для любых Android-устройств
│   └── MedRisunok_v1.0.30_arm64.apk       # Оптимизированный для 64-битных планшетов/смартфонов
├── windows/
│   ├── MedRisunok_Setup_v1.0.30.exe       # Полноценный инсталлятор с ярлыками и деинсталлятором
│   └── MedRisunok_v1.0.30_portable.zip    # Переносимая версия (запуск без установки с флешки)
└── ios/
    └── MedRisunok_v1.0.30_unsigned.ipa    # Установочный пакет IPA (без подписи)
```

### 1. Сборка на Windows (Android + Windows)
В терминале PowerShell из корня проекта выполните команду:

* **Собрать всё сразу (Windows + Android):**
  ```powershell
  .\scripts\build_all_windows.ps1
  ```
* **Или раздельно:**
  ```powershell
  .\scripts\build_windows.ps1    # Сборка Setup.exe и Portable ZIP
  .\scripts\build_android.ps1    # Сборка Universal и Arm64 APK
  ```

*Примечание:* Скрипт сборщика Windows автоматически находит компилятор Inno Setup 6 (`ISCC.exe`) и собирает полноценный `MedRisunok_Setup_v1.0.30.exe`.

---

### 2. Сборка на macOS (виртуальная машина или Mac)
Для сборки неподписанного пакета iOS IPA перейдите в корень проекта на macOS и запустите:

```bash
chmod +x scripts/build_ios_unsigned.sh
./scripts/build_ios_unsigned.sh
```

**Что делает скрипт:**
1. Выполняет `flutter pub get` и `pod install`.
2. Компилирует релизную сборку без подписи: `flutter build ios --release --no-codesign`.
3. Упаковывает скомпилированный бандл `Runner.app` в стандартизированную структуру `Payload/`.
4. Создает готовый архив `dist/ios/MedRisunok_v1.0.30_unsigned.ipa`.

---

### 3. Автоматическая облачная сборка (GitHub Actions CI/CD)
В проекте настроен пайплайн [.github/workflows/build_installers.yml](file:///d:/projects/med_scheme/.github/workflows/build_installers.yml). 

При пуше в ветку `main` или ручном запуске через вкладку **Actions -> Run workflow**:
* GitHub сам запускает виртуальную машину `ubuntu` и собирает APK для Android;
* Запускает виртуальную машину `windows` и собирает Setup.exe + Portable ZIP;
* Запускает виртуальную машину `macos` и собирает неподписанный `.ipa` для iOS;
* Все готовые файлы прикрепляются в виде скачиваемых архивов во вкладке запуска.

## Часть 2. Инструкция по установке для пользователей и врачей

### 📱 Android (Планшеты и смартфоны)
1. Скопируйте файл `MedRisunok_v1.0.30_universal.apk` (или `_arm64.apk`) на устройство через USB, Telegram, облачный диск или локальную сеть.
2. Откройте файл в стандартном файловом менеджере устройства.
3. Если система запросит разрешение на установку приложений из этого источника, нажмите **«Настройки»** и включите тумблер **«Разрешить установку из этого источника»**.
4. Нажмите **«Установить»**.
5. При первом запуске приложение предложит выбрать рабочую папку на планшете для сохранения проектов и отчетов.

---

### 💻 Windows (ПК и ноутбуки)

#### Вариант А: Установщик (Рекомендуется)
1. Запустите файл `MedRisunok_Setup_v1.0.30.exe`.
2. Мастер установки на русском языке предложит путь установки (по умолчанию `C:\Program Files\MedRisunok`) и создание ярлыка на Рабочем столе.
3. Нажмите **«Установить»** и затем **«Завершить»**.
4. Приложение зарегистрировано в системе и может быть удалено в любой момент через стандартный раздел Windows «Установка и удаление программ».

#### Вариант Б: Portable (Без установки)
1. Распакуйте архив `MedRisunok_v1.0.30_portable.zip` в любую папку (или на внешнюю флешку).
2. Запустите `med_scheme.exe`.

---

### 🍏 iOS (iPad и iPhone — Установка неподписанного IPA)

Файл `.ipa` без официальной цифровой подписи Apple нельзя установить обычным тапом, так как операционная система iOS блокирует неподписанный исполняемый код. 

Для установки на iPad врача используется один из следующих быстрых и бесплатных способов:

#### Способ 1: Установка через Sideloadly (Самый простой и быстрый способ, Windows / Mac)
*Утилита Sideloadly устанавливается на ПК или Mac и подписывает IPA бесплатным личным Apple ID прямо в момент установки по кабелю или Wi-Fi.*

1. Скачайте и установите бесплатную программу **[Sideloadly](https://sideloadly.io/)** на ваш компьютер (Windows или Mac).
2. Подключите iPad к компьютеру по кабелю (и нажмите на iPad «Доверять этому компьютеру», если появится запрос).
3. Откройте Sideloadly:
   * Перетащите файл `MedRisunok_v1.0.30_unsigned.ipa` в окно программы.
   * В поле **Apple ID** введите свой Apple ID (любой бесплатный аккаунт).
   * Нажмите кнопку **«Start»**.
4. Программа автоматически подпишет приложение и установит его на iPad за 30–60 секунд.
5. **Активация на iPad (только при первой установке):**
   * Откройте на iPad: **Настройки -> Основные -> VPN и управление устройством**.
   * Найдите строку с вашим Apple ID, нажмите на нее и нажмите **«Доверять»**.
   * После этого ярлык «МедРисунок» будет запускаться в штатном режиме.

---

#### Способ 2: Установка через AltStore (Windows / Mac)
1. Установите **AltServer** на ПК/Mac с официального сайта [altstore.io](https://altstore.io/).
2. Установите AltStore на подключенный iPad через меню AltServer.
3. В приложении AltStore на самом iPad перейдите во вкладку **«My Apps»**, нажмите кнопку **«+»** в верхнем углу и выберите файл `MedRisunok_v1.0.30_unsigned.ipa`.
4. AltStore установит и будет автоматически обновлять приложение по локальному Wi-Fi.

---

#### Способ 3: TrollStore (Если планшет поддерживает)
Если на iPad установлена версия iOS, поддерживающая **TrollStore** (iOS 14.0 — 16.6.1 / 17.0):
1. Отправьте `MedRisunok_v1.0.30_unsigned.ipa` на iPad (через AirDrop или Files).
2. Нажмите «Поделиться» -> открыть в **TrollStore**.
3. Приложение установится навсегда без ограничений по сроку действия сертификата.
