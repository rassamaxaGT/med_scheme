Here is how you can improve the main editor layout for tablets:

1. Open `lib/main.dart`.
2. Add a `Row` widget as the main body.
3. Put the buttons in a column inside the row.
4. Put the drawing canvas on the right side of the row.

- Change layout to Row in main.dart
- Create a widget for tool buttons
