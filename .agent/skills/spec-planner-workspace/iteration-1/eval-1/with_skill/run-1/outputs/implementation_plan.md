# План реализации: Сервис синхронизации SQLite с удаленным API

## Этапы разработки
- **Этап 1: Базовая настройка базы данных**
  - Подключить `sqflite` and `path` пакеты в `pubspec.yaml`.
  - Добавить служебную таблицу `sync_metadata` для отслеживания времени последней синхронизации и версий записей.
- **Этап 2: API Клиент и Логика Синхронизации**
  - Разработать `SyncApiClient` с методами получения (`pull`) и отправки (`push`) данных.
  - Реализовать метод `SyncService.performSync()`, который получает новые данные, сравнивает версии и записывает в SQLite. Конфликтные записи перезаписываются данными с сервера.
- **Этап 3: Фоновая синхронизация**
  - Подключить пакет `workmanager`.
  - Настроить вызов `SyncService.performSync()` при запуске приложения и раз в 15 минут в фоновой задаче.
- **Этап 4: Интеграция и Тестирование**
  - Реализовать обработку ошибок сети и повторные попытки (retry policy).
  - Написать тесты для проверки стратегии разрешения конфликтов "сервер всегда выигрывает".

## Риски и особенности
- **Фоновый режим на iOS**: Строгие ограничения ОС на фоновые задачи могут приводить к тому, что интервал в 15 минут будет неточным.
- **Размер транзакций**: При большом объеме данных синхронизацию следует выполнять пакетами (batching) внутри одной транзакции SQLite.
