# План реализации: Медицинский графический редактор («раскраска» для УЗИ-врачей)

План разделен на 5 последовательных фаз, спроектированных так, чтобы минимизировать количество блокировок из-за зависимостей.

## Фазы разработки

### Фаза 1: Базовая настройка проекта и структура Clean Arch
- Настройка `pubspec.yaml`: подключение `flutter_bloc`, `shared_storage` (для Android SAF), `archive` (для ZIP-контейнера проектов), `path_provider` (для iOS), `get_it` (для DI).
- Создание структуры каталогов по слоям Clean Architecture.
- Конфигурация iOS `Info.plist` (добавление ключей `UIFileSharingEnabled` и `LSSupportsOpeningDocumentsInPlace`).
- Разработка базовых классов сущностей: `DrawAction`, `Project`, `DrawActionModel` (с JSON-сериализацией векторов).

### Фаза 2: Движок рисования и базовый холст
- Создание `CanvasWidget` с `GestureDetector` для сбора локальных точек штриха.
- Реализация `DrawBloc` для хранения истории штрихов (`history`) и управления Undo / Redo.
- Разработка `CanvasPainter` (CustomPainter) для рендеринга путей из BLoC.
- Реализация базовых инструментов: Карандаш (одинарная линия), Ластик.
- Поддержка Palm Rejection (игнорирование случайных касаний пальцами при активном стилусе) и чувствительности к давлению стилуса (`PointerEvent.pressure`).

### Фаза 3: Сложные кисти и маркеры (Core Canvas Features)
- Реализация алгоритмов на основе `PathMetrics` в `CanvasPainter` для рисования:
  - Кисти «колючая проволока» (инфильтрат).
  - Кисти «паутина» (спайки).
- Реализация геометрических фигур:
  - Овал (Эндометриома — шоколадный, Миома — бледно-розовый).
  - Стрелки с текстом (вызов диалогового окна для ввода текста при завершении рисования стрелки).
- Поддержка фиксированных штампов: ВМС (спираль), очаг (пятно).

### Фаза 4: Работа с файловой системой и проекты .meddraw
- Реализация сервиса сохранения/загрузки проектов:
  - Сериализация метаданных проекта и списка действий в JSON.
  - Упаковка JSON + фонового изображения в `.meddraw` (Zip) с использованием пакета `archive` в изоляте (`compute`), чтобы не блокировать интерфейс.
- Настройка Scoped Storage на Android:
  - Реализация запроса директории сохранения проектов при первом запуске через `shared_storage` (использование `ACTION_OPEN_DOCUMENT_TREE`).
  - Сохранение постоянного persistable URI.
- Настройка iOS: автоматический экспорт созданных проектов в Documents приложения (чтобы отображались в Files).
- Реализация функции плоского экспорта готовой схемы в JPEG/PNG галерею устройства.

### Фаза 5: Импорт пользовательских штампов и полировка интерфейса
- Разработка механизма загрузки кастомных PNG в качестве штампов.
- Верстка планшетного интерфейса: левая панель инструментов (выбор кистей, штампов, ластика, цвета), центральная область холста, верхняя панель (Undo, Redo, Сохранить, Выход).
- Финальное тестирование и оптимизация производительности CustomPaint на больших схемах.

## Риски и сложности
- **Производительность отрисовки**: При очень большом количестве штрихов CustomPaint может лагать. Необходимо использовать оптимизацию отрисовки (растеризация старых штрихов в фоновое изображение при превышении порога, либо кеширование путей в `Picture`).
- **Фоновое сохранение**: Упаковка архива может вызывать просадку FPS, поэтому изоляты (`compute`) для ZIP обязательны.
